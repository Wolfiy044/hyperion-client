One launcher for all your Minecraft profiles.

Hyperion Client is a Windows launcher for Minecraft: Java Edition. Create profiles for any game version and mod loader, install modpacks from Modrinth and CurseForge, and manage mods, logs and screenshots in one place.

JAVA EDITION WINDOWS FABRIC · FORGE · NEOFORGE · QUILT

Profiles as cards

Every profile has its own game folder, memory settings and icon.

Modpacks and content

Browse Modrinth and CurseForge, import packs, and keep mods up to date.

Import from other launchers

Bring instances over from Modrinth App, CurseForge, Prism, MultiMC and PolyMC.

Sign in with Microsoft

Hyperion Client uses the official Microsoft sign-in to verify that you own Minecraft.

Hyperion Client is an independent project. It is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.
