Hyperion Client

Hyperion Client is a launcher for Minecraft: Java Edition on Windows. I started it because I play a lot of different modpacks and wanted one place where every profile has its own game folder, its own memory settings and its own icon.

You can create a profile for any game version with Fabric, Forge, NeoForge or Quilt, install modpacks from Modrinth and CurseForge, or bring instances over from other launchers like Prism, MultiMC or the Modrinth and CurseForge apps. Inside a profile you can switch mods on and off, check them for updates, read the game logs and look through your screenshots.

To start the game the launcher signs you in with your Microsoft account and checks that you own Minecraft. That happens through the normal Microsoft login, so your password never goes through this app.

The project is still in development and there is no public download yet.

Hyperion Client is an independent project and has nothing to do with Mojang or Microsoft. Minecraft is a trademark of Mojang Studios.
