Hyperion Client

I have been playing Minecraft for over nine years. In that time, the game has changed a lot, and mods have taken it even further. Launchers have been around for years too, but I kept missing things I wanted in my own setup. One was a launcher that could handle more of the performance settings for me without needing another mod just for that. Eventually, I decided to build my own.

With our German roleplay server, MetropoliaRP, getting ready to launch, we needed a launcher for its modpack anyway. That gave me a reason to start Hyperion. But I did not want people to install it for our server and have no use for it anywhere else. I wanted them to be able to keep their other Minecraft profiles and packs in it too.

Each profile has its own game folder and settings. You can bring over an existing instance or install a pack from Modrinth or CurseForge, then manage its updates without mixing it up with another pack. Hyperion Boost can adjust Java memory and thread settings for your hardware when enabled, without installing a performance mod. How much that helps depends on the computer and the pack; it is not a guaranteed FPS increase.

I also wanted it to be easier to get everyone into the same game. Friends can chat in the launcher, make a party and share a server or modpack invitation before opening Minecraft. Community servers have their own page where players can find the right profile. You can keep Hyperion in the tray while playing and choose whether other people can see your presence or server address.

Cheating was another concern for our server. I did not want the server-side anti-cheat to be our only layer, so I looked into checks on the player's side and built Hyperion Anti-cheat. For an enabled protected session, it checks the selected server profile's modpack and settings as well as the Minecraft process for signs of tampering. It is an additional layer alongside the server's checks, not a guarantee that every cheat will be caught.

Before you play

Hyperion is a free Windows launcher, with no in-app purchases. You still need to own Minecraft: Java Edition. Signing in opens Microsoft's normal login and checks your Minecraft license; your password is entered on Microsoft's page. If you are signed out of Hyperion, starting a profile opens the separately installed official Minecraft Launcher, which uses its own account.

The current build needs Windows 10 version 1809 or newer and the .NET 8 Desktop Runtime. Downloads and online features need an internet connection. The game itself may need more memory or different hardware depending on the pack. Fabric, Forge, NeoForge and Quilt are available where those loaders support the chosen Minecraft version, rather than for every version.

Hyperion is still in development. The Microsoft Store submission is being prepared, but the app has not been published there. There is no public download on this website yet.

A note about anti-cheat

Some servers enable Hyperion Anti-cheat or require it to join. For those sessions, Hyperion asks for your consent and Windows administrator permission before starting a separate native user-mode process. It checks the selected profile and the Minecraft process, then sends findings to Hyperion's backend so the server can check admission. It does not install a custom kernel driver or Windows service.

The current guard can delete resource or shader packs from that profile if it identifies them as x-ray packs. If you decline permission or a required check fails, the protected start is blocked. Ordinary unprotected profiles do not run the guard. Anti-cheat cannot guarantee that a server is free of cheating. The privacy notice explains what information is processed.
