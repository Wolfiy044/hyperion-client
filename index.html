Hyperion Client

I started Hyperion because I play different Minecraft modpacks and wanted to keep them in one place. Each profile has its own game folder and settings, so changing one pack does not get in the way of another. You can bring over an existing instance or install a pack from Modrinth or CurseForge, then manage its mods and updates inside the launcher. Logs and screenshots stay with the profile they belong to.

Hyperion has also grown into a way to play together. You can talk to friends before opening Minecraft, make a party and invite them to your server or modpack. Groups and community chat give those conversations somewhere to stay, and game nights help arrange the next session. You decide whether your presence and server address are visible. Blocking, reporting and moderation appeals are available when needed.

The server page shows published communities and their status. If a server has a pack, you can install its profile from there. Owners manage their listings and rules through the Hyperion portal. The launcher can stay in the tray while you play; its settings let you change startup behavior and skip the intro. Profile tools provide backups and load timings to help when a pack needs attention.

The in-game client mod is on hold for now. Hyperion does not install it or include it in exported packs, and its switches are hidden. Chat and parties still work in the launcher. There is no current in-game mod compatibility offer.

Before you play

Hyperion is a free Windows launcher, with no in-app purchases. You still need to own Minecraft: Java Edition. Signing in opens Microsoft's normal login and checks your Minecraft license; your password is entered on Microsoft's page. If you are signed out of Hyperion, starting a profile opens the separately installed official Minecraft Launcher, which uses its own account.

The current build needs Windows 10 version 1809 or newer and the .NET 8 Desktop Runtime. Downloads and online features need an internet connection. The game itself may need more memory or different hardware depending on the pack. Fabric, Forge, NeoForge and Quilt are available where those loaders support the chosen Minecraft version, rather than for every version.

Hyperion is still in development. The Microsoft Store submission is being prepared, but the app has not been published there. There is no public download on this website yet.

A note about anti-cheat

Some servers enable Hyperion Anti-cheat or require it to join. For those sessions, Hyperion asks for your consent and Windows administrator permission before starting a separate native user-mode process. It checks the selected profile and the Minecraft process, then sends findings to Hyperion's backend so the server can check admission. It does not install a custom kernel driver or Windows service.

The current guard can delete resource or shader packs from that profile if it identifies them as x-ray packs. If you decline permission or a required check fails, the protected start is blocked. Ordinary unprotected profiles do not run the guard. Anti-cheat cannot guarantee that a server is free of cheating. The privacy notice explains what information is processed.
