Hyperion Client

Manage Minecraft: Java Edition profiles and modpacks, connect with friends and browse community servers in one Windows launcher. Hyperion Client is free and has no in-app purchases.

Profiles and content

Create separate game folders with their own memory settings, Java options and icons. Import Modrinth and CurseForge packs or instances from other launchers. Browse mods, manage updates, repair profiles, read logs and manage screenshots.

Friends and parties

Send friend requests, chat, form parties and share invitations or modpacks. Groups, community chat and scheduled game nights keep people together.

Privacy and moderation

Control presence, hide your server address, limit requests and block users. Report messages, review moderation notices and submit appeals in the launcher.

Community servers

Browse published servers, check their status and install associated server profiles. Server owners manage listings, packs and rules through the Hyperion portal.

Launcher settings

Configure startup, the intro, closing to the tray and behavior after launching a game. Profile performance tools include load timings, backups and configurable JVM tuning.

Game starts and compatibility

Microsoft sign-in uses official authentication and checks Minecraft ownership. Your password is entered on Microsoft's page. When signed out of Hyperion, a game start opens the separately installed official Minecraft Launcher with its independent account session.

The current build requires Windows 10 version 1809 or later and the .NET 8 Desktop Runtime. Internet access is needed for downloads and online features. Minecraft requirements depend on the selected version and modpack.

Vanilla, Fabric, Forge, NeoForge and Quilt profiles use versions supported by each loader. Not every loader exists for every Minecraft version; universal compatibility is not promised.

Protected server sessions

Servers can set Hyperion Anti-cheat to off, optional or required. A protected session starts a separate native user-mode process after consent and Windows administrator permission. It checks profile content and Minecraft process integrity and reports findings to Hyperion for server admission checks. No custom kernel driver or Windows service is installed.

The current implementation may delete resource or shader packs from the selected profile that it identifies as x-ray packs. Declining permission or failing required checks prevents the protected start. Unprotected profiles do not activate the guard. These checks do not guarantee a cheat-free server. See Privacy for the information processed.

In-game UI is paused

The native in-game client mod is temporarily disabled. Its controls are hidden, it is not installed or included in exported modpacks, and no active loader/version support is offered for it. Friends, chat and parties remain available in the launcher.

Availability

The project is in development. A Microsoft Store submission is being prepared, but it has not been published there. No public download is currently offered here. Minecraft is a separate product; a valid Java Edition license is required to play.
